# GHL + Instagram messaging navigation

## Turn on Instagram DMs in GHL (confirmed 2026-11-17, Olly did it live)
GHL → Settings → **Integrations** (NOT "Private Integrations": that page has a "Create" button and only makes API keys) → Instagram tile → @attractwitholly is already listed ("Direct Instagram", connected via Social Planner) → switch **Enable messaging + automation** ON → Save. No login was asked for.
